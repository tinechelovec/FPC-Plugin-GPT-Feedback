# ⭐ GPT Feedback — инструкция по установке и настройке

Привет! Это альтернативная инструкция для **GPT Feedback** — плагина для FunPay Cardinal, который автоматически отвечает на отзывы покупателей с помощью искусственного интеллекта.

Плагин получает отзыв покупателя, анализирует его вместе с информацией о заказе и создаёт подходящий персональный ответ.

> Основная инструкция: https://teletype.media/@tinechelovec/GPT-Feedback
> GitHub: https://github.com/tinechelovec/FPC-Plugin-GPT-Feedback

---

# 📌 Что делает GPT Feedback

GPT Feedback умеет:

* автоматически отвечать на отзывы FunPay;
* отдельно выбирать оценки от **1⭐ до 5⭐**, на которые нужно отвечать;
* анализировать текст отзыва;
* учитывать оценку покупателя;
* учитывать имя покупателя;
* учитывать название товара;
* учитывать описание товара;
* учитывать стоимость заказа;
* учитывать дату и время покупки;
* автоматически определять язык отзыва;
* отвечать на том же языке;
* выбирать стиль общения;
* добавлять или запрещать эмодзи;
* ограничивать длину ответа;
* добавлять собственную подпись продавца;
* использовать разные AI-модели;
* автоматически переключаться на резервную модель;
* реагировать на изменение отзыва;
* удалять свой ответ, если покупатель удалил отзыв;
* повторять неудачную отправку после перезапуска Cardinal;
* вести статистику;
* сохранять подробные логи;
* тестировать AI API прямо из Telegram;
* обновляться через интерфейс плагина.

---

# 🚀 Установка

Для работы GPT Feedback нужен установленный **FunPay Cardinal**.

После установки Cardinal:

1. скачайте актуальный файл GPT Feedback;
2. откройте Telegram-бота Cardinal;
3. отправьте:

```text
/menu
```

4. перейдите в раздел **«Плагины»**;
5. загрузите `.py`-файл GPT Feedback;
6. откройте установленный плагин.

При первом входе в настройки GPT Feedback попросит сначала прочитать инструкцию.

После ознакомления нажмите:

**✅ Прочитал**

После этого откроется основное меню настроек.

**⚙️ Настройки**

# ⚙️ Основные настройки

На главной странице отображаются:

* состояние плагина;

Основные кнопки:

# 🔘 Включение плагина

Кнопка:

**✅ Плагин включён**

или:

**❌ Плагин выключен**

полностью включает или выключает автоматическую обработку отзывов.

Если GPT Feedback выключен, новые отзывы автоматически не обрабатываются.

Для первоначальной настройки можно сначала оставить плагин выключенным, настроить API, стиль и оценки, а уже потом включить его.

---

# 🔑 API-ключ

Для генерации ответов GPT Feedback использует AI API.

Откройте:

**⚙️ Настройки → 🔑 API ключ**

и отправьте свой ключ.

После сохранения в главном меню будет отображаться:

```text
API ключ: ✅ задан
```

Сам ключ показывается только в сокращённом виде.

> ⚠️ API-ключ является приватными данными.
>
> Не отправляйте его другим людям и не публикуйте в открытом доступе.

---

# 🧪 Тест API

После добавления ключа желательно сразу нажать:

**🧪 Тест API**

Плагин выполнит тестовый запрос к выбранной AI-модели.

Это позволяет проверить:

* правильный ли API-ключ;
* доступен ли API;
* работает ли выбранная модель;
* может ли плагин получить ответ.

Лучше выполнить тест до включения автоматических ответов.

---

# ⭐ Настройка отзывов

В этом разделе выбирается, **на какие оценки GPT Feedback должен отвечать**.

Можно отдельно включить:

* **1⭐**
* **2⭐**
* **3⭐**
* **4⭐**
* **5⭐**

Например, если включены только:

```text
4⭐
5⭐
```

то GPT Feedback будет автоматически отвечать только на отзывы с оценкой 4 или 5 звёзд.

Отзывы на 1–3 звезды будут оставлены без автоматического ответа.

---

# ⭐ Можно выбрать несколько оценок

Оценки работают независимо.

Например:

```text
✅ 1⭐
✅ 2⭐
⬜ 3⭐
✅ 4⭐
✅ 5⭐
```

В этом случае плагин будет работать со всеми оценками, кроме 3⭐.

Полностью выключить все оценки нельзя.

Хотя бы одна оценка всегда должна оставаться активной.

---

# 🧠 Как GPT Feedback отвечает на разные оценки

AI учитывает не только текст отзыва, но и количество звёзд.

Поэтому реакция меняется в зависимости от оценки.

---

## 5⭐

Для положительного отзыва ответ обычно:

* благодарит покупателя;
* реагирует на конкретный текст;
* сохраняет позитивный тон;
* может добавить подходящее пожелание.

---

## 4⭐

Плагин понимает, что отзыв положительный, но не максимальный.

Ответ остаётся доброжелательным и не пытается спорить с покупателем.

---

## 3⭐

Используется более нейтральная реакция.

GPT Feedback старается:

* поблагодарить за обратную связь;
* учесть замечание;
* не вести себя так, будто отзыв полностью положительный.

---

## 1–2⭐

Для негативных отзывов плагин должен отвечать серьёзнее.

Он не должен:

* шутить над покупателем;
* спорить с ним;
* обвинять его;
* использовать неуместный сленг;
* писать слишком радостный ответ.

Ответ должен спокойно реагировать на проблему и учитывать содержание самого отзыва.

# 🤖 Модель ИИ

Показываются:

* текущая модель;
* состояние автоматического переключения;
* количество доступных моделей.

После добавления рабочего API-ключа GPT Feedback может получить список доступных моделей непосредственно из API.

# 🔄 Обновить список API

Кнопка:

**🔄 Обновить список API**

заново загружает доступные модели.

Используйте её, если:

* добавили новый API-ключ;
* нужная модель не отображается;
* модель стала недоступна;
* появились новые модели;
* список отображается неправильно.

---

# 🛟 Автоматический переход на резервную модель

GPT Feedback умеет автоматически менять AI-модель, если основная временно перестала работать.

Например, это может произойти при:

* превышении лимита;
* Rate Limit;
* перегрузке модели;
* временной недоступности;
* ошибках сервера;
* удалении модели из API.

Если автоматический переход включён, плагин попробует другие доступные текстовые модели.

Когда рабочая модель найдена, она может быть сохранена как новая основная.

---

# 📏 Длина ответа

Можно выбрать желаемый диапазон длины ответа.

Доступны варианты примерно от:

```text
100–200 символов
```

до:

```text
800–900 символов
```

Вы выбираете верхнюю границу, а плагин формирует диапазон шириной примерно 100 символов.

Например, значение:

```text
500
```

означает диапазон:

```text
400–500 символов
```

---

# 📏 Длина контролируется автоматически

GPT Feedback старается соблюдать выбранный диапазон достаточно строго.

Если AI создал слишком короткий ответ, плагин может попробовать сгенерировать его повторно.

Если ответ получился слишком длинным, он сокращается.

В выбранный лимит также входит **подпись продавца**, если она настроена.

Поэтому не стоит делать очень длинную подпись при маленьком лимите ответа.

---

# 😊 Эмодзи в ответах

В разделе детальных настроек есть переключатель:

**😊 Эмодзи в ответах**

Если функция включена, AI может использовать подходящие эмодзи.

Например:

```text
Спасибо большое за отзыв! 😊
```

Если функция выключена, GPT Feedback удаляет эмодзи из итогового ответа.

Это удобно, если вы хотите более строгий или деловой стиль.

---

# 🎨 Стиль сообщений

GPT Feedback поддерживает несколько готовых стилей общения.

---

## 🧠 Адаптивный

Стандартный и самый универсальный режим.

AI подстраивается под конкретного покупателя:

* уровень формальности;
* настроение;
* длину сообщения;
* манеру общения.

При этом GPT Feedback не должен просто копировать слова покупателя.

Структура ответа может отличаться от отзыва к отзыву.

---

## 🙂 Дружелюбный

Более тёплый и неформальный стиль.

GPT Feedback общается как доброжелательный владелец небольшого магазина.

Используются:

* простые фразы;
* более человеческая благодарность;
* неформальное обращение;
* тёплые пожелания.

---

## 🤝 Деловой

Более официальный вариант.

GPT Feedback:

* обращается на «Вы»;
* использует грамотные полные предложения;
* избегает сленга;
* отвечает спокойно и профессионально.

Подходит для магазинов, которым нужен более официальный стиль.

---

## 🔥 Молодёжный

Более короткий и энергичный стиль.

В положительных отзывах может использоваться умеренный современный сленг.

Например:

```text
топ
круто
кайф
```

Но для негативных отзывов на **1–2⭐** сленг автоматически становится неуместным, поэтому ответ должен быть серьёзным.

---

## ✨ Премиальный

Сдержанный и аккуратный стиль персонального менеджера.

GPT Feedback старается писать:

* спокойно;
* уверенно;
* вежливо;
* без сленга;
* без лишнего пафоса;
* без большого количества восклицаний.

---

## 🎭 Игривый

Для положительных отзывов допускается немного юмора или лёгкая игра слов.

Юмор используется только там, где он действительно подходит.

Для отзывов на **1–3⭐** GPT Feedback должен отвечать серьёзно и без шуток.

---

# ✍️ Подпись продавца

Можно добавить собственную подпись, которая будет автоматически вставляться в конец каждого ответа.

Например:

```text
С уважением, tinechelovec
```

Тогда итоговый ответ может выглядеть так:

```text
Спасибо за отзыв! Рад, что всё прошло хорошо.

С уважением, tinechelovec
```

---

# ✏️ Настройка подписи

Откройте:

**🛠 Детальные настройки → ✍️ Подпись продавца**

и отправьте нужный текст одним сообщением.

Максимальная длина подписи:

```text
240 символов
```

Чтобы удалить подпись, отправьте:

```text
-
```

Подпись добавляется отдельной строкой внизу ответа.

---

# 🧾 Поля заказа и отзыва

Здесь можно выбрать, какие данные GPT Feedback передаёт AI при создании ответа.

Доступны:

* **Имя покупателя**
* **Название товара**
* **Описание товара**
* **Стоимость**
* **Оценка**
* **Текст отзыва**
* **Дата покупки**

Каждое поле можно отдельно включить или выключить.

---

# 👤 Имя покупателя

Если включено, AI получает имя покупателя.

Это позволяет при необходимости сделать ответ немного более персональным.

Если не хотите передавать имя AI, поле можно выключить.

---

# 🛒 Название товара

Передаёт название купленного товара.

Полезно, чтобы ответ соответствовал конкретной покупке.

Например, AI сможет понимать, что человек купил:

* игру;
* аккаунт;
* подписку;
* Telegram Stars;
* цифровой ключ;
* услугу.

---

# 📝 Описание товара

Позволяет AI учитывать описание FunPay-лота.

Это помогает не создавать совершенно оторванные от товара ответы.

Но если описание содержит большой объём текста, учитывайте, что эти данные отправляются внешнему AI API.

---

# 💰 Стоимость

Передаёт стоимость заказа.

При необходимости можно отключить, если цена не нужна для формирования ответов.

---

# ⭐ Оценка

Оценка всегда используется плагином служебно, чтобы правильно определить настроение ответа.

Но настройка **«Оценка»** определяет, разрешено ли AI прямо упоминать число звёзд в тексте.

Например, если поле включено, возможна формулировка:

```text
Спасибо за 5 звёзд!
```

Если выключено, AI всё равно понимает, положительный или негативный отзыв, но не должен напрямую писать число оценки.

---

# 💬 Текст отзыва

Одно из самых важных полей.

Если оно включено, AI получает непосредственно текст покупателя.

Например:

```text
Всё быстро, продавец помог с активацией
```

После этого ответ может реагировать именно на эту информацию.

Если текст отзыва отключить, персонализация станет значительно слабее.

---

# 📅 Дата покупки

Передаёт AI дату и время оформления заказа.

При необходимости поле можно выключить.

---

# 🌐 Язык ответа

Отдельно выбирать язык не нужно.

GPT Feedback автоматически определяет язык по самому отзыву.

Например:

Покупатель написал:

```text
Everything worked perfectly, thank you!
```

GPT Feedback должен ответить на английском.

Если отзыв написан на русском — ответ будет на русском.

---

# 🧠 Как создаётся ответ

Упрощённо процесс выглядит так:

1. покупатель оставляет отзыв;
2. Cardinal получает событие нового отзыва;
3. GPT Feedback определяет номер заказа;
4. загружает данные заказа;
5. проверяет оценку;
6. проверяет, включена ли эта оценка в настройках;
7. собирает разрешённые поля;
8. определяет язык отзыва;
9. формирует запрос для AI;
10. получает ответ;
11. проверяет длину;
12. при необходимости удаляет эмодзи;
13. добавляет подпись продавца;
14. отправляет ответ на FunPay;
15. сохраняет информацию о результате.

---

# 🔄 Изменение отзыва

GPT Feedback реагирует не только на новый отзыв, но и на **изменение существующего**.

Например, сначала покупатель оставил:

```text
5⭐
Всё отлично
```

плагин ответил.

Позже покупатель изменил отзыв на:

```text
3⭐
Сначала всё было хорошо, но потом появилась проблема
```

GPT Feedback определит, что отзыв изменился, и при подходящих настройках создаст новый ответ на основании обновлённого текста.

---

# 🗑 Удаление отзыва

Если покупатель полностью удалил свой отзыв, GPT Feedback может удалить и автоматически опубликованный ответ продавца.

Это позволяет не оставлять ответ там, где самого покупательского отзыва больше нет.

---

# 🚫 Отзывы на отключённые оценки

Если оценка не включена в:

**⭐ Настройка отзывов**

GPT Feedback не будет оставлять на неё автоматический ответ.

Например:

```text
Включено: 4⭐, 5⭐
```

Покупатель изменил отзыв с 5⭐ на 2⭐.

Если плагин раньше отвечал на этот отзыв, а новая оценка больше не входит в разрешённые, старый автоматический ответ может быть удалён.

---

# 👤 Собственные покупки

GPT Feedback старается не обрабатывать отзывы, связанные с вашими собственными покупками.

Плагин предназначен для ответов **продавца покупателям**, а не для автоматизации ваших собственных отзывов в роли покупателя.

---

# 🔁 Очередь повторной отправки

Если AI или FunPay временно вернули ошибку, заказ не обязательно теряется.

GPT Feedback сохраняет проблемный заказ в очередь повторной обработки.

Например, ошибка может произойти на этапе:

* проверки API-ключа;
* получения заказа;
* обращения к AI;
* отправки ответа на FunPay.

Плагин сохраняет номер заказа и информацию об ошибке.

---

# ♻️ Повтор после перезапуска

После перезапуска Cardinal GPT Feedback проверяет очередь неудачных ответов.

Если там находятся заказы, плагин автоматически попробует обработать их ещё раз.

Например:

1. покупатель оставил отзыв;
2. AI API временно не работал;
3. заказ попал в очередь;
4. вы перезапустили Cardinal;
5. GPT Feedback снова пробует создать ответ;
6. если всё прошло успешно, заказ удаляется из очереди.

Это помогает не терять отзывы из-за временных ошибок.

---

# 🔔 Уведомления об ошибках

При серьёзной ошибке GPT Feedback может отправить уведомление в Telegram.

В сообщении указывается:

* номер заказа;
* этап обработки;
* текст ошибки.

Например:

```text
Заказ: #ABC123
Этап: генерация ответа
Ошибка: API temporarily unavailable
```

Если заказ поставлен в очередь, плагин сообщает, что после перезапуска будет выполнена новая попытка.

---

# 📊 Статистика

В разделе:

**📊 Статистика**

показывается статистика работы GPT Feedback.

Можно посмотреть:

* успешно опубликованные ответы;
* количество ошибок;
* сколько заказов добавлено в очередь;
* сколько успешно обработано после перезапуска;
* сколько повторных попыток закончилось ошибкой;
* сколько заказов сейчас ждут повтора;
* дату последнего успешного ответа.

Также есть статистика отдельно по оценкам:

```text
1⭐
2⭐
3⭐
4⭐
5⭐
```

Так можно быстро посмотреть, на какие отзывы плагин отвечал чаще всего.

---

# 📜 Логи плагина

GPT Feedback ведёт подробный журнал работы.

В логах фиксируются:

* получение нового отзыва;
* номер заказа;
* вызовы AI;
* используемая модель;
* успешные ответы;
* ошибки;
* автоматическое переключение модели;
* повторные попытки;
* удаление или изменение отзывов.

---

# 📄 Скачать полный лог

При открытии раздела логов GPT Feedback может отправить отдельный TXT-файл с полной историей.

Это удобно, если нужно:

* найти конкретную ошибку;
* отправить лог разработчику;
* посмотреть, почему ответ не был опубликован;
* проверить работу fallback-моделей.

Перед отправкой логов другим людям всё равно рекомендуется убедиться, что в них нет информации, которую вы не хотите раскрывать.

---

# 🤖 Какие данные уходят AI

GPT Feedback использует внешний AI API.

В зависимости от включённых настроек туда могут передаваться:

* имя покупателя;
* название товара;
* описание товара;
* стоимость;
* оценка;
* текст отзыва;
* дата покупки.

Отключить ненужные данные можно в разделе:

**🧾 Поля заказа и отзыва**

Если вы не хотите отправлять какое-либо поле внешнему AI, просто выключите его.

---

# 🔐 Где хранятся настройки

Основные настройки GPT Feedback хранятся локально в папке плагина.

В них сохраняются:

* состояние плагина;
* выбранные оценки;
* API-настройки;
* выбранная модель;
* настройки fallback;
* длина ответа;
* эмодзи;
* стиль;
* подпись;
* выбранные поля.

Также отдельно сохраняется состояние уже обработанных отзывов и очередь повторных попыток.

---

# 🔄 Обновление

В главном меню есть кнопка:

**🔄 Обновить**

GPT Feedback поддерживает обновление плагина из Telegram-интерфейса.

Перед обновлением рекомендуется сохранить важные настройки и убедиться, что вы используете официальный файл из репозитория.

---

# 🗑 Удаление

В главном меню есть кнопка:

**🗑 Удалить плагин**

Перед удалением появляется подтверждение.

После удаления файла плагина рекомендуется перезапустить Cardinal, чтобы старые Telegram-обработчики полностью перестали работать.

# 💬 Примеры

## Положительный отзыв

Покупатель:

```text
5⭐
Всё супер, быстро получил товар!
```

В дружелюбном стиле GPT Feedback может ответить примерно в таком направлении:

```text
Спасибо большое за отзыв! Рад, что всё прошло быстро и без проблем. Буду ждать тебя снова!
```

Точный ответ каждый раз генерируется AI и может отличаться.

---

# 💬 Негативный отзыв

Покупатель:

```text
2⭐
Возникла проблема с активацией
```

GPT Feedback должен учитывать негативную оценку и содержание сообщения.

Ответ должен быть серьёзным и аккуратным, без неуместных шуток и чрезмерно позитивного тона.

---

# 🌍 Отзыв на другом языке

Покупатель:

```text
Great seller, everything was fast!
```

GPT Feedback автоматически определяет английский язык и формирует ответ на английском.

---

# ✍️ Ответ с подписью

Если установлена подпись:

```text
С уважением, MyStore
```

она будет добавлена снизу:

```text
Спасибо за отзыв! Рад, что покупка прошла успешно.

С уважением, MyStore
```

---

# ❓ Если GPT Feedback не отвечает

Проверьте по порядку:

1. включён ли плагин;
2. прочитана ли инструкция при первом запуске;
3. добавлен ли API-ключ;
4. проходит ли **«Тест API»**;
5. доступна ли выбранная AI-модель;
6. включена ли нужная оценка;
7. действительно ли покупатель оставил отзыв;
8. не является ли это вашей собственной покупкой;
9. не находится ли заказ в очереди повторной обработки;
10. что написано в логах.

---

# ❓ Если AI выдаёт ошибку

Попробуйте:

1. открыть **«Детальные настройки»**;
2. открыть **«Модель и автопереход»**;
3. нажать **«Обновить список API»**;
4. выбрать другую модель;
5. включить автоматический переход;
6. выполнить **«Тест API»**.

Если ошибка была временной, неудачный отзыв также может быть повторно обработан после перезапуска Cardinal.

---

# ❓ Если ответ слишком длинный

Откройте:

**🛠 Детальные настройки → 📏 Длина ответа**

и установите меньший диапазон.

Не забывайте, что подпись продавца тоже входит в общий лимит.

---

# ❓ Если ответы слишком одинаковые

Попробуйте стиль:

**🧠 Адаптивный**

Он специально предназначен для того, чтобы менять композицию ответов и подстраиваться под конкретного покупателя.

Также убедитесь, что включено поле:

**💬 Текст отзыва**

Без него AI получает значительно меньше индивидуального контекста.

---

# ✅ Рекомендуемая первая настройка

Если используете GPT Feedback впервые:

1. установите плагин;
2. прочитайте инструкцию;
3. пока оставьте плагин выключенным;
4. добавьте API-ключ;
5. выполните **«Тест API»**;
6. выберите рабочую AI-модель;
7. включите автопереход;
8. оставьте стиль **Адаптивный**;
9. установите длину примерно **400–500 символов**;
10. выберите только **5⭐**;
11. оставьте включённым текст отзыва и название товара;
12. включите плагин;
13. дождитесь первого нового отзыва;
14. проверьте созданный ответ;
15. после этого при желании добавьте 4⭐, 3⭐ и негативные оценки.

Так проще всего сначала проверить качество ответов на положительных отзывах.
